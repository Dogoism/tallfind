# tallfind
Tall Clothing Hub

## Repository protection

Tallfind store listings are reviewed data. Before merging changes, especially updates to `data/*.json`, verify the store URL, tall sizing details, tops/bottoms availability, and any inseam claims from a reliable source.

Recommended GitHub protection settings for the default branch:

- Require a pull request before merging.
- Require at least one approval.
- Require review from Code Owners.
- Require the `Validate data and formatting` status check to pass after the workflow has run once.
- Block force pushes and branch deletion.
