# Security Policy

## Reporting a vulnerability

If you find a security issue in Tallfind, please do not open a public issue.
Report it privately to the repository owner, or use GitHub private vulnerability reporting if it is enabled for this repository.

Please include:

- A clear description of the issue
- Steps to reproduce it
- The affected page or file
- Any suggested fix, if you have one

## Scope

In scope:

- Cross-site scripting or unsafe rendering issues
- Unsafe external link handling
- Leaked secrets or credentials
- Form abuse risks
- Deployment or GitHub configuration issues

Out of scope:

- General feature requests
- Store listing disagreements unless they create a security or privacy risk
- Issues that require attacking third-party stores
